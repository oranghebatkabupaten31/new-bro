SATRYOTECH — FLAT GITHUB PAGES PACKAGE
========================================

This package keeps the original project folders AND provides root-level copies
for simple static deployment.

ROOT-LEVEL DEPLOY FILES
- index.html
- style.css
- script.js
- image/photo copies (also retained in assets/)
- cv.pdf (also retained in assets/)

ORIGINAL FOLDERS PRESERVED
- assets/
- CSS/
- JS/
- Script/
- Java/
- Python/
- .vscode/

DEPLOY
1. Extract this ZIP.
2. Upload ALL contents inside this folder to the root of your GitHub repository.
3. In GitHub: Settings > Pages > Deploy from a branch.
4. Select branch main and folder /(root), then Save.

The website entry page is the root index.html. It uses root style.css and script.js,
and its image references continue to use assets/ so the original folder copies remain
available. Root-level image duplicates are included as requested.
